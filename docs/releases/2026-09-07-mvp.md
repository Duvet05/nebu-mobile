# Simplified Android release

This is a product-wide reduction, not a reviewer-only mode or remote flag.

- Retire the Home Explore section, knowledge search and voice session history entry points. Legacy URLs redirect to Home.
- Retire new voice cloning, its screen, upload methods and the native `record` plugin family.
- Preserve personality selection, the directly accessible personality catalog and its Playground, child profiles, accounts, toy pairing, settings, memory and walkie-talkie.
- Preserve existing cloned voices and customer data. Owners can still select or explicitly remove an existing voice. No server APIs, data migrations or production data were changed.
- Make voice and personality sheets scroll above system navigation, including enlarged text. Replace the personality `{name}` placeholder with the toy's name.
- Keep optional analytics and crash reporting off without a saved choice; honor prior explicit choices.

## Verification

Flutter analysis and tests cover the full app, removed feature policy, catalog navigation, child/profile route preservation, existing voice data and scrollable pickers at 1.1x and 2x text. The store screenshot harness uses fictional data and a mocked API; it never creates server consent or writes customer records.

The new signed CI artifact still needs a Samsung runtime check before submission. This change does not close Data safety: optional SDK collection, retained child profiles, live voice providers and previously distributed versions must still be reflected accurately. Do not submit a production release solely because these features were removed.

Removed source files remain recoverable through Git history. Existing accounts, profiles and voices are not deleted.
